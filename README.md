# protonminingco.com

This repository publishes [protonminingco.com](https://protonminingco.com). It holds no site
files: each publish builds the site from its source and deploys it to GitHub Pages.

`SOURCE_SHA` names the source commit to publish. Updating it on `main` starts a publish;
**Actions → Publish protonminingco.com → Run workflow** republishes the current one.
